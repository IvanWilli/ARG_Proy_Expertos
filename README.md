# Proyecciones de población de Argentina con expertos

Proyecto en R que combina una encuesta a expertos con datos demográficos para simular trayectorias de fecundidad, mortalidad y migración, y proyectar la población argentina entre 2025 y 2075.

- `R/`: scripts de análisis y proyección.
- `data/`: insumos demográficos y respuestas estandarizadas.
- `encuesta/`: cuestionario y base de expertos.
- `resultados/`: simulaciones y tablas generadas.
- `plots/`: gráficos del análisis.

El orden de ejecución indicado es: `distr_conjunta.R`, `mort.R`, `fec.R`, `migr.R` y `pop.R`. Las rutas de datos y resultados son relativas a la raíz del proyecto.
